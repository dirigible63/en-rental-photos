# EN Rental Photos — Build 1.0
Static GitHub Pages prototype. Upload index.html and app.js to repository root, then Settings > Pages > Deploy from a branch > main / (root). Open the published URL on a phone.

Test with non-sensitive sample photos. Select files, enter date, six-digit contract and unit (letters, digits, underscores and hyphens), then Test upload. Save individual test JPEGs to compare quality. Next unit retains date and contract. Photos are processed locally; no cloud upload or persistence. Browser-native decoding may not support HEIC. JPEG conversion strips original metadata; capture metadata preservation is deferred to production. No authentication, SharePoint integration, retrieval or retention in this build. Do not use as an operational record system yet.
